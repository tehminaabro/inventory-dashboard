# 📊 Inventory Dashboard

A responsive **Inventory Management Dashboard** created as a web development practice project. I built this dashboard while following a YouTube tutorial and used it to practice and understand the structure of modern dashboard interfaces.

The project helped me gain practical experience with **HTML, CSS, JavaScript, dashboard layouts, KPI cards, navigation components, and data visualization**.

## 🚀 Live Demo

👉 **[View Inventory Dashboard](https://tehminaabro.github.io/inventory-dashboard/)**

You can visit the live demo above to explore the dashboard interface directly in your browser.

## ✨ Features

* 📊 Inventory overview dashboard
* 📦 Inventory-related KPI cards
* 📈 Data visualization and charts
* 🧭 Sidebar navigation
* 🖥️ Clean dashboard layout
* 📱 Responsive interface
* 🌐 Deployed using GitHub Pages

## 🛠️ Technologies Used

* **HTML** – Structure of the dashboard
* **CSS** – Styling and responsive layout
* **JavaScript** – Interactive functionality
* **ApexCharts** – Data visualization
* **GitHub Pages** – Deployment and hosting

## 🎯 Purpose of the Project

This project was created as a **learning and practice project** while following a YouTube tutorial. My goal was to understand how a professional-looking dashboard is structured and how different UI components such as navigation bars, KPI cards, tables, and charts work together.

Building this project gave me practical experience that I can use in my future web development and data-related projects.

## 📚 Learning Note

This dashboard was developed with the help of a YouTube tutorial/reference. The project is kept as part of my learning portfolio to demonstrate my practice with **frontend development and dashboard UI design**.
